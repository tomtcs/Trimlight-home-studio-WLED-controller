Trimlight Home Studio · WLED

This WLED edition is a lighting app for a house roofline: a library of animated looks, an editor, sections, playlists and a nightly schedule. It needs a wider screen. Open the link on a laptop or desktop.

WLED connection & setup

Connect this browser to a WLED controller on the same local network, then confirm the number of LEDs and color order for each output.

Controller connection

Controller address, home photo, and channel settings are saved with this installation.

Channel count is the controller’s maximum capacity; you can populate fewer outputs. It does not assign GPIO pins. Configure the outputs and pins in WLED first, then test the connection.

Used for local sunset previews and WLED sunset timers. The timezone remains the one configured in WLED.

Choose demo mode or enter a WLED address and test the connection.

Backup & restore

Export patterns, schedules, roof sections, controller setup, photos, and traced rooflines to a JSON file.

Restore replaces the app’s current saved data. It restores this app’s controller settings; it does not write configuration back to the WLED device.

Network requirement: WLED's browser API uses HTTP and WebSocket. Open this app over HTTP on the same trusted LAN; an HTTPS-hosted page cannot connect directly to WLED's unencrypted ws:// socket. Never expose the controller API to the public internet.

Before connecting hardware

  1. Record the current controller settings and label each low-voltage data run before disconnecting anything.
  2. Confirm pixel voltage, protocol, color order, ground reference, and maximum current from the light and power-supply documentation.
  3. Check that the WLED controller supports the required voltage and pixel protocol. Select output pins from that controller's documentation.
  4. Calculate each run's pixel count and total load; set conservative power limits appropriate for the supply and wiring.

Configure WLED

  1. Set the LED type, color order, output pins, and pixel count for each run.
  2. Configure the device name, network connection, time zone, and location only if a local schedule needs sunset timing.
  3. Test each run at low brightness with a simple static color before trying animated effects.
  4. Verify direction, grouping, spacing, and power behavior on the installed system before saving a schedule.

Power and wiring are installation-specific. Do not assume a controller output can power the pixels directly, that two devices share a compatible ground, or that a pin map from another installation applies to yours. Follow the manufacturers' wiring diagrams and have a qualified electrician handle mains-voltage work.
